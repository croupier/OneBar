Установка OneBar

Проверенный APK, контрольная сумма и понятные шаги. Сайт не содержит кнопки самообновления: новую версию вы всегда скачиваете сами.

Минимальная версия

Android 8.0

Формат

Универсальный APK

Лицензия

MIT

1. Скачайте файлы релиза

В GitHub Releases выберите последнюю неотмеченную как pre-release версию. Скачайте OneBar-<версия>.apk и SHA256SUMS. Не используйте APK из случайных зеркал и сообщений.

2. Проверьте SHA-256

Откройте терминал в папке с загруженными файлами и сравните хеш с содержимым SHA256SUMS.

Windows PowerShell

Get-FileHash .\OneBar-0.15.0.apk -Algorithm SHA256

macOS / Linux

shasum -a 256 OneBar-0.15.0.apk

Замените 0.15.0 на версию скачанного релиза. Совпадение хеша подтверждает, что файл не изменился после публикации.

3. Установите APK

  1. Откройте APK в файловом менеджере или браузере.
  2. Если Android покажет предупреждение, разрешите установку из этого источника для выбранного приложения. Название пункта зависит от прошивки.
  3. Подтвердите установку и откройте OneBar.
  4. Выберите язык. Доступ к контактам можно не выдавать — поиск по приложениям и веб-подсказки продолжат работать.
Совет по безопасности. После установки разрешение «Устанавливать неизвестные приложения» можно отключить. OneBar не запрашивает его сам.

Обновления и подпись

Обновляйте APK из GitHub Releases поверх текущей версии. Для сохранения данных новая сборка должна быть подписана тем же ключом. Если вы установите версию из F-Droid, а затем захотите перейти на GitHub (или наоборот), Android может потребовать удаление и повторную установку из-за другой подписи. Перед этим экспортируйте или запишите важные локальные данные.

Если что-то не работает

Android блокирует установку

Разрешите установку из выбранного браузера/файлового менеджера в системных настройках. На корпоративном или защищённом устройстве политика может запрещать sideload — тогда установите сборку через разрешённый канал.

«Приложение не установлено»

Проверьте версию Android, свободное место и SHA-256. Если уже установлена копия с другим ключом подписи, сохраните нужные данные, удалите её и установите APK заново.

Нет контактов

Выдайте OneBar доступ к контактам в системных настройках. На некоторых прошивках контакты хранятся только в локальном аккаунте или SIM и не доступны через стандартный провайдер.

Нет веб-подсказок

Проверьте интернет и настройку «Веб-подсказки». Запрос должен содержать минимум три символа. Локальный поиск от этого не зависит.

Аналитика недоступна

В сборке не задан API-ключ AppMetrica. Это нормально для исходной или F-Droid-сборки: приложение полностью работает без аналитики.
