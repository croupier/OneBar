Приватность

Редакция от 28 ноября 2026 года · приложение OneBar и сайт проекта

Коротко: контакты, история и избранное остаются на устройстве. OneBar не читает SMS и журнал звонков. Веб-подсказки отправляют введённый текст в Google только при включённой опции. AppMetrica и Umami включаются отдельно и по умолчанию выключены.

1. Кто обрабатывает данные

OneBar — некоммерческий учебный проект croupier. Приложение работает без аккаунта и без собственного сервера. Автор получает данные только через добровольно включённую аналитику или сообщение, отправленное пользователем через обратную связь.

2. Локальные данные

  • Приложения. OneBar запрашивает список установленных приложений через Android PackageManager. Названия пакетов используются для поиска, истории запусков и избранного.
  • Контакты. После разрешения READ_CONTACTS приложение читает контактные данные для поиска. OneBar не загружает их на собственный сервер.
  • История. Локально сохраняются недавно открытые приложения, действия СМС/звонков, связанные с контактами идентификаторы, имена, номера и явно отправленные поисковые запросы.
  • Избранное и настройки. Хранятся на устройстве. Очистка истории удаляет поисковые запросы; избранное и настройки меняются отдельно.

Системный backup/перенос контактов, истории, избранного и настроек зависит от Android и устройства. Согласие на аналитику исключено из backup, чтобы при переносе оно снова требовалось явно. Удаление данных приложения или сброс устройства удаляет локальную информацию.

3. Разрешения Android

РазрешениеЗачем
INTERNETВеб-подсказки, веб-поиск и включённая аналитика.
READ_CONTACTSПоиск по контактам и открытие карточки контакта.
QUERY_ALL_PACKAGESПолный список установленных приложений для поиска.

READ_SMS, READ_CALL_LOG, доступ к геолокации, камере, микрофону и рекламным идентификаторам не запрашиваются.

4. Сетевые сервисы приложения

Google completion

При включённых веб-подсказках текст поисковой строки и язык интерфейса отправляются в Google completion по HTTPS после короткой задержки. Это отдельная настройка, её можно выключить: локальный поиск по приложениям и контактам продолжит работать. Нажатие «Яндекс» или «Google» открывает соответствующий поиск в браузере; к нему применяются правила выбранного сервиса.

AppMetrica — только по согласию

В релизной сборке с настроенным API-ключом AppMetrica может собирать технические сведения об устройстве и ОС, сессии и обобщённые события: открытие OneBar, отправка поиска, запуск приложения, звонок/СМС, избранное и выбор поисковой системы. SDK инициализируется с отправкой, выключенной по умолчанию, до явного включения в «Настройки → Приватность». SDK создаёт собственный `appmetrica_device_id` для объединения сессий; OneBar не задаёт пользовательский профиль или рекламный ID.

OneBar не передаёт тексты запросов, имена, номера, содержание сообщений, названия пакетов и пользовательские идентификаторы. Рекламные ID, App Set ID, геолокация, автоматические crash- и ANR-отчёты отключены. GMS исключён; MIT-адаптер App Set ID остаётся только для совместимости SDK и использует штатный fallback без идентификатора; Уже переданные обезличенные данные нельзя отозвать, но новые события прекращают отправляться сразу после выключения.

Сервис предоставляет YANDEX LLC. По документации AppMetrica обезличенные данные обрабатываются на серверах в ЕС и Российской Федерации. Подробности: уведомление AppMetrica и условия использования.

5. Аналитика сайта

Сайт использует Umami только после нажатия «Разрешить» в отдельном уведомлении. До согласия скрипт аналитики не загружается. Umami работает без cookies и, по заявлению сервиса, не собирает персональные данные и не отслеживает пользователя между сайтами.

После согласия могут обрабатываться страница, referrer, приблизительные технические данные браузера/устройства и обезличенные события вроде перехода к скачиванию. Текст демонстрационного поиска не передаётся — только количество найденных результатов. Бесплатный Umami Hobby предусматривает до 100 000 событий в месяц и хранение 6 месяцев; серверы находятся в США и ЕС. Отказ или отзыв согласия доступны в уведомлении и подвале сайта.

Если владелец проекта не настроил Umami website ID, аналитика сайта не работает и уведомление не показывается.

6. GitHub и обратная связь

GitHub Pages и GitHub Releases принимают стандартные технические данные запросов, включая IP-адрес, по правилам GitHub. APK скачивается непосредственно с GitHub. Обратная связь отправляется только по действию пользователя в его почтовое приложение; к письму добавляются версия OneBar, производитель, модель и версия Android, которые можно удалить перед отправкой.

7. Ваш выбор

  • Отключить веб-подсказки и аналитику в настройках приложения.
  • Отозвать доступ к контактам в системных настройках Android.
  • Очистить поисковую историю или удалить избранное в приложении.
  • Отклонить аналитику сайта или отозвать согласие через «Настройки аналитики» в подвале.
  • Удалить приложение, чтобы удалить его локальные данные.

8. Дети и изменения

OneBar не ориентирован специально на детей. Проект не продаёт данные и не показывает рекламу. Если политика или набор сетевых сервисов изменятся, дата редакции и описание будут обновлены до публикации соответствующей версии.
