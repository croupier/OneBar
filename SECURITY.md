# SECURITY

OneBar — некоммерческий проект без программы выплат за уязвимости. Поддерживается последняя опубликованная версия.

## Сообщить об уязвимости

Не создавайте публичный issue для проблемы, которая может привести к утечке контактов, номеров, истории, ключа подписи или обходу разрешений.

Напишите на [onebar@3406.ru](mailto:onebar@3406.ru) с темой `OneBar security`. Укажите:

- затронутую версию и commit/tag;
- модель и версию Android;
- описание сценария и влияние;
- минимальные шаги воспроизведения;
- возможный исправляющий патч, если он есть.

Не прикладывайте реальные персональные данные, чужие контакты, токены, keystore или пароли. Ответ Best-effort, сроки не гарантируются.

## Ключ подписи

APK из GitHub Releases должен быть подписан release-ключом. Утечка keystore или паролей считается критическим инцидентом: остановите выпуск, сохраните доказательства, свяжитесь с владельцем и подготовьте новый ключ с планом миграции. Не коммитьте `keystore.properties`, `*.jks` и `*.keystore`.

## Проверка релиза

Перед установкой сравните SHA-256 APK с `SHA256SUMS` из того же GitHub Release. Не скачивайте APK из сторонних зеркал. Инструкция находится на сайте проекта.
