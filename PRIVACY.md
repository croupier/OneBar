# Политика приватности OneBar

Редакция: 28 ноября 2026 года.

OneBar — некоммерческий учебный Android-проект croupier. Приложение не требует аккаунта, не показывает рекламу и не использует собственный сервер для хранения пользовательских данных.

## Кратко

- Контакты, история, избранное и настройки остаются на устройстве.
- OneBar не читает SMS и журнал звонков.
- Веб-подсказки отправляют введённый текст в Google completion только при включённой опции.
- AppMetrica включается отдельно, по умолчанию выключена и не получает тексты запросов или контактные данные.
- Аналитика сайта Umami загружается только после согласия.

## Локальные данные

| Данные | Где хранятся | Назначение |
|---|---|---|
| Недавно открытые приложения и счётчики запусков | Локальный DataStore | История и сортировка |
| Контактные ID, lookup key, имена, номера, время СМС/звонков | Локальный DataStore | История действий |
| Отправленные поисковые запросы | Локальный DataStore | Повторный выбор запроса |
| Избранные приложения и контакты | Локальный DataStore | Быстрый доступ |
| Настройки темы, языка, поиска и клавиатуры | SharedPreferences | Поведение приложения |
| Согласие на AppMetrica | SharedPreferences, исключено из backup | Уважение opt-in |

OneBar читает контакты через стандартный Android provider только после разрешения. Названия пакетов приложений используются для поиска, истории и избранного. Удаление данных приложения удаляет локальную информацию.

Системный backup и перенос между устройствами зависят от Android и прошивки. История исключена из правил backup; согласие на аналитику также исключено, чтобы на новом устройстве оно снова требовалось явно.

## Разрешения

- `INTERNET` — веб-подсказки, браузерный поиск и включённая аналитика.
- `READ_CONTACTS` — поиск и открытие контактов.
- `QUERY_ALL_PACKAGES` — полный список установленных приложений.

`READ_SMS`, `READ_CALL_LOG`, геолокация, камера, микрофон и рекламные идентификаторы не запрашиваются.

## Google completion

Если веб-подсказки включены, текст из поисковой строки и язык интерфейса отправляются в Google completion по HTTPS. Опция отключается в настройках; локальный поиск продолжает работать без сети. Кнопки Яндекс и Google открывают поиск в браузере, после чего применяются правила соответствующего сервиса.

## AppMetrica

В сборке с настроенным API-ключом SDK инициализируется с `withDataSendingEnabled(false)`. Отправка включается только после явного действия пользователя в «Настройки → Приватность».

При согласии AppMetrica может получать:

- технические сведения об устройстве и Android;
- версию приложения, сессии и длительность использования;
- обобщённые события: `app_open`, `search_submitted`, `app_launched`, `contact_call`, `contact_sms`, `web_search_yandex`, `web_search_google`, изменения избранного и режима избранного.

SDK создаёт собственный `appmetrica_device_id` для объединения сессий. OneBar не задаёт собственный профиль или рекламный ID.

OneBar не передаёт тексты запросов, имена, номера, содержание сообщений, названия пакетов, пользовательские ID и устойчивые идентификаторы. Рекламные ID, App Set ID, геолокация, автоматические crash- и ANR-отчёты отключены. Необязательные ad revenue, billing, identifiers, location и screenshot модули исключены из Gradle-зависимостей. MIT-адаптер App Set ID оставлен для совместимости SDK, но GMS исключён; без GMS SDK использует собственный fallback и не получает App Set ID.

Выключение аналитики прекращает отправку новых событий. Уже полученные сервисом обезличенные данные нельзя отозвать. Сервис предоставляет YANDEX LLC; согласно документации, данные обрабатываются на серверах в ЕС и Российской Федерации.

## Сайт и Umami

Сайт не загружает Umami без согласия. Umami заявляет об работе без cookies, сборе только обезличенных данных и отсутствии межсайтового отслеживания. После согласия могут обрабатываться страница, referrer, технические данные браузера и события переходов. Текст демо-поиска не отправляется — только количество результатов.

Бесплатный Umami Hobby предусматривает 1 сайт, 100 000 событий в месяц и 6 месяцев хранения. Серверы Umami Cloud находятся в США и ЕС. Отзыв согласия доступен в подвале сайта. Если website ID не задан, аналитика не работает.

## GitHub и обратная связь

GitHub Pages и GitHub Releases получают стандартные технические данные запросов, включая IP-адрес, и обрабатывают их по своим правилам. Обратная связь отправляется только по действию пользователя через почтовое приложение. К письму добавляются версия OneBar, производитель, модель и Android; эти сведения можно удалить перед отправкой.

## Ваш выбор

- Отключите аналитику и веб-подсказки в настройках OneBar.
- Отзовите доступ к контактам в системных настройках Android.
- Очистите историю поиска или удалите избранное.
- Отклоните аналитику сайта или отзовите согласие в подвале.
- Удалите приложение для удаления локальных данных.

## Дети и изменения

OneBar не ориентирован специально на детей. Проект не продаёт данные. Если политика или сетевые сервисы изменятся, дата редакции и описание будут обновлены до выпуска соответствующей версии.
