# Changelog

Все заметные изменения проекта документируются здесь. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — semver 2.0.0 без pre-release суффиксов.

## [Unreleased]

### Added

- Презентационный сайт на Tailwind CSS с адаптивным дизайном, демо поиска, SEO и GitHub Pages workflow.
- MIT-лицензия, политика приватности, contributing/security и релизная документация.
- Fastlane-метаданные RU/EN, feature graphic и скриншоты для F-Droid/IzzyOnDroid.
- Opt-in AppMetrica 8.6.0 с обезличенными событиями и настройкой в «Приватность».
- Исключение GMS, рекламных ID, App Set ID, location, billing, ad revenue и screenshot модулей AppMetrica.
- Согласие на аналитику Umami для сайта с отзывом в подвале.
- CI, GitHub Actions release workflow, APK checksums и информация о сертификате подписи.

### Changed

- README стал публичной документацией проекта.
- Согласие на аналитику исключено из системного backup и переноса.
